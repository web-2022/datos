# Mis datos

App en español para ingresar nombre, correo, teléfono, ciudad y una descripción personal. La tarjeta se actualiza mientras escribes.

## Uso

Abre `index.html` en tu navegador. No requiere instalación ni compilación.

- **Guardar mis datos** guarda la información en el almacenamiento local del navegador.
- **Borrar todo** elimina los datos guardados en este navegador.
- Los datos del formulario no se envían a un servidor ni se guardan en este repositorio.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages**. Selecciona **Deploy from a branch**, la rama **main**, la carpeta **/ (root)** y pulsa **Save**.

La dirección prevista es https://web-2022.github.io/datos/ y estará disponible cuando GitHub termine la publicación.
